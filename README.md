# Du Lei Personal Website

Built with **Astro** (zero client-framework JS overhead, calm dark minimalist layout, bilingual `/` & `/en/`, print-ready resume & PDF export, live footer quality self-check, `/rss.xml`, and `/llms.txt`).

## Commands

```bash
npm run dev      # Start local dev server
npm run build    # Build static site into dist/
npm run preview  # Preview production build
```
